# 地面瓶子仿真验证

日期：2026-09-10，Jetson Orin / Ubuntu 20.04 / ROS 2 Foxy / Gazebo 11.15.1 / MoveIt 2.2.3。

## 场景与假设

- 移除台座，机器人轮子按上游几何落在 z=0 地面，底盘固定。
- 近似 550 ml 瓶型：高 227 mm、直径 64 mm；假设空瓶 25 g、装水 150 ml，总质量 175 g。
- A=(0.275, -0.000941) m，B=(0.320, -0.000941) m，瓶子竖直落地；夹持高度 105 mm，计划抬升 50 mm。
- 平行夹爪接触垫为 50×50×10 mm 的仿真改型。机器人惯性和从动机构有数值简化，机械臂关闭重力；瓶子保留重力、接触和摩擦。
- 高度、质量、摩擦、几何不等同于实物标定；不测瓶壁变形、压痕或液体晃动。

## 模型与异常检查

`python3 -m unittest discover -s tests -v`：8 项通过。

覆盖模型拓扑、独立自由度、联动规划组、URDF/正逆运动学一致性、场景落地与初始间隙、电机限位，以及任务节点的四类非法请求：几何不可达、受关节限位约束的无有效逆解、非有限坐标、夹爪开口不足。四类请求均退出码 1、输出明确错误、运动事件列表为空。原始记录见 [非法请求记录](validation/bottle/invalid-requests.json)。

任务还检查主关节反馈、关键从动关节误差（≤0.03 rad）、瓶子实际抬升、搬运保持、直立与放置稳定性。出现问题即停止后续动作；动作等待超时时请求取消，不盲目回位或松爪。

## 调试中发现并修复的问题

1. 原小方块的接触垫不适合直接用来评价圆柱瓶，接触面高度改为 50 mm；扩大前后长度时曾导致初始模型重叠，最终保留 50 mm 长度并设置初始间隙。
2. 更关键的是同轴虚拟关节的极小惯性使 ODE 在瓶子负载下失去联动跟随。实际夹爪发生倾斜，而主关节仍报告到位。虚拟连杆使用有限惯性做数值正则化，加入从动关节误差检查。
3. 夹持后瓶子仍会发生少量滑移。规划中的附着碰撞体会在抬升/搬运后按实际位姿刷新，下降终点根据当前夹持偏移修正，避免把瓶子压进地面。

这些修复属于简化仿真模型调试，不能解释为已经修复或验证了真实 EP 夹爪。

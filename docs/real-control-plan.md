# 真机准备方案（仅设计，未实施）

## 先判断瓶子是否适合

- 550 ml 是容量，不规定瓶子的质量、刚度或统一 CAD 尺寸。需要测量实际批次的直径、高度、空瓶/装水总重和夹持位置。
- DJI EP 官方规格给出两轴臂、约 100 mm 夹爪开口。DJI EP Core 支持页给出夹持力 5 N、最大抬升能力 200–300 g；同类 EP 机构仍应核对手中具体型号和安装方式。满瓶仅水就约 550 g，不能作为原装臂已满足的负载。
- 空瓶会变形；部分装水也不保证夹持区域不变形。可先用带盖轻载瓶、较低夹持功率和宽接触垫实验，观察压痕与打滑。若需要内部支撑，应把新增重量计入总重，并确认课程允许改装目标物。
- 参数中的 150 ml 水和 25 g 瓶体只是当前仿真假设，不是抗变形方案。刚体仿真成功不能证明实物无损。

## 通信与控制适配

1. 固定 EP、确认机械臂/夹爪组装、零位、电池、供电、固件和可用急停方式。Jetson 使用合适的独立供电；不要按通用课程“USB 连接”假定 USB 就能控制 EP。
2. Jetson 与 EP 建立官方 SDK 支持的网络连接。先只读设备版本、机械臂位置和状态，再在人员监护下低速动作。
3. 保持 ROS 2 任务层、规划接口和轨迹 Action；编写独立 EP 硬件后端，代替 `ep_gazebo_control`。接收规划结果，转换为官方 SDK 的机械臂/夹爪命令，返回动作状态、超时和取消结果。
4. SDK 的机械臂 `move/moveto(x,y)` 用毫米，x 向前、y 向上；仿真用 world 的 x/z 和米。必须标定坐标原点、TCP、关节零位和映射，不能直接把 URDF 的关节角原样发送。SDK 不天然等价于定时 JointTrajectoryController，需验证路径跟踪和速度能力。
5. 订阅 SDK 机械臂位置/舵机状态，发布一致的 ROS 2 状态；物体位置观测改用传感器；当前闭环放置补偿依赖瓶子相对夹爪的实际位姿，不能直接用期望位姿冒充测量。若没有视觉/其他观测，需要单独设计经过验证的接触释放策略；人工验收只能替代成绩判定，不能直接替代在线滑移补偿。固定点任务可先测量 A/B，若课程要求视觉识别再加相机定位。
6. 用配置选择 sim/real 后端，保持上层任务逻辑一致。这一适配器尚未编写，也未连接实机。

## 递进验证

空载回位/移动/停止 → 轻质刚体 → 低装水瓶 → 5 次固定 A/B 取放。每步低速测试，一人操作、一人急停观察。先确认取消动作、通信超时、关节限位、目标不可达能停止；不要在未知姿态或通信异常后盲目执行“回零”。

最终记录位置误差、成功率、打滑、瓶身压痕/损坏、停止响应和每位组员操作结果，并保存视频。达到这些条件前，不把仿真指标当作真机验收。
